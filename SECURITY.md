# Security Policy

## Supported Versions

Only the latest release of the plugin receives security fixes. Please update to the
newest version from the [Releases page](https://github.com/Terrorwolf01/opendeck-helldivers2/releases)
before reporting an issue.

| Version | Supported |
| ------- | --------- |
| 3.x     | ✅        |
| < 3.0   | ❌        |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately via GitHub's
[private vulnerability reporting](https://github.com/Terrorwolf01/opendeck-helldivers2/security/advisories/new).

Please include:

- a description of the vulnerability and its impact,
- steps to reproduce it, or a proof of concept,
- the plugin version and operating system you used.

## Disclosure Process

- You will normally receive an acknowledgement within 7 days.
- I will investigate, keep you updated on progress, and work on a fix.
- Once a fixed release is published, the vulnerability will be disclosed in a GitHub
  Security Advisory, crediting you unless you prefer to stay anonymous.

Please give me a reasonable amount of time to fix the issue before any public disclosure.
